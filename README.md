# LibraryLINQ



1. Milline on DbContexti ülesanne?



DbContext võimaldab rakendusel suhelda andmebaasiga. Sellega saab andmeid lisada lugeda kustutada uuendada  ja määrab Db tabelid



2\.  Miks ei ole hea paigutada kõiki andmebaasipäringuid otse kasutajaliidese koodi?



Muudab koodi lugemise keerulisemaks ja raskesti hooldavaks. Andmebaasipäringute eraldamine aitab hoida koodi korras ning teeb kergemaks testimist.



3\. Millisesse kihti paigutaksid andmebaasiga suhtlemise MVC- või VIPER-arhitektuuris? Põhjenda oma vastest.



MVC-arhitektuuris kuna ei tea et oleksin isegi mis asi on VIPER-arhitektuur. Ailt lugedes nende vahe on kergem kasutada  MVC-arhitektuuri kuna see vastutab andmete ja andmetega seotud toimingute eest sellega on andmebaasiloogika kasutajaliidesest eraldatud.
